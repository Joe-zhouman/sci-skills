## ① Hedging 三档（证据强度 ↔ 措辞强度对表）

| 档 | 动词 / 短语 | 什么时候够格 |
|---|---|---|
| 强 | 表明 / 证实 / 揭示 / 确认 / 给出 | 设计与数据直接支撑：有对照、有统计检验、直接测量——主结果句用这档 |
| 中 | 提示 / 反映 / 与……一致 / 可能源于 / 指向 | 解释合理但非决定性：单一实验、间接推断、趋势级观察 |
| 弱 | 或可归因 / 似乎 / 尚待验证 / 有待检验 | 超出直接观察的推测：机理猜想、外推、类比 |

选档三问：数据是直接测的还是推的？有没有对照 / 检验？换个解释还说得通吗？——第三问答"说得通"，至少降一档。

各档用出来的样子：

- 强（有对照 + 统计）：消融实验表明，移除多尺度分支后 mAP 下降 4.2 个百分点（表 5）。
- 中（趋势级）：两个数据集上的增益方向一致，提示该机制不依赖特定纹理背景。
- 弱（机理猜想）：该平台期或可归因于表面反应与体扩散的速率竞争，尚待原位观测检验。

**同类证据同档，全稿一致**——同类证据在这章用"表明"、那章用"或可归因"，是跨章 voice 裂缝（`references/polish-strategy.md` §⑥）。

配套纪律：

- **降档是 polish 的常规动作，升档几乎从不是**（升档 = 造假主张——与 `references/style-guardrails.md` §① 同一条纪律的正反两面）。
- 模块正文（method-results 对）用强 / 中档；弱档的家在小结与总结展望章（机理解释不进模块正文——写作链纪律，polish 不搬动位置）。

## ② Transition（过渡连接）

| 族 | 短语 | 备注 |
|---|---|---|
| 递进 | 在此基础上 / 进一步地 / 进而 | 递进要真有"基础"——前句确是后句的前提 |
| 转折 | 然而 / 相比之下 / 与此不同 | 标准连接词，不是 AI 痕迹（校准见 `references/chinese-register.md` §①） |
| 因果 | 因此 / 由此 / 据此 | "据此"自带依据指向，方法章好用 |
| 让步 | 尽管如此 / 虽然如此 | 让步后必须真转：下一句是真的转折，不是原路继续 |

用**最小够用**的连接词，不逐句装饰；两句关系自明时，连接词是冗余。

- 改写前（连接词装饰 + 填充叠加）：此外，值得注意的是，该方法还具有较低的计算开销。
- 改写后：该方法的计算开销也较低（单帧 23 ms，表 2）。

## ③ Limitation（局限表述）

- 本研究的适用范围限于……（条件 / 样本 / 场景）。
- 本研究未涵盖……；……情形留待后续检验。
- 尚不能排除……的可能性；另一不确定性来源是……。
- 上述解释基于……假设；若该假设不成立，则……
- 结果的外推需谨慎：本文结论在……条件下取得，向……外推尚缺证据。

**配具体不确定性来源，不配空谦抑**："存在一定局限"零信息；"局限在于样本仅覆盖三种牌号低碳钢，高合金体系未验证"才是局限句。

## ④ 展望（从 boundary 落 next question）

- 后续可针对……开展……（挂在具体 limitation 上）。
- 值得进一步检验的是……（点名要检验什么）。
- 若……成立，本方法可扩展到……（条件式外推，条件即 boundary）。
- 下一步工作是在……上验证……（更大样本 / 别的场景）。

反例（空洞，删或重写）："未来可以进一步研究"——没说研究什么、为什么。每个展望项挂一个具体 boundary / limitation（与 `references/chinese-register.md` §⑦ 展望空洞同源；写作侧的展望 hook 属 summary，polish 复检同一标准）。

- 改写前（空洞）：未来可以对本文模型进行进一步优化。
- 改写后（boundary 落地）：模型在长宽比大于 5 的缺陷上召回率偏低（§4.4）；后续可针对细长形态设计各向异性卷积核并检验。

## ⑤ 与前文比较

一致：

- 与……的结论一致。
- 本文观察支持了……的报道。
- 这与……的结果相符。

分歧（公平对待对方工作）：

- 不同于……，本文得到……；可能的原因是……（样本 / 条件 / 方法差异）。
- 与……的报道相反，一个可能的解释是……

分歧句的样子："本文测得的活化能（62 kJ·mol⁻¹）低于 Liu 等[9]报道的 78 kJ·mol⁻¹；可能的原因是本文原料纯度更高（§2.1），也可能是测温位置差异所致。"

分歧句纪律：给对方的结果留解释空间——差异原因落在条件差异上，不落在"他们做错了"上（对前人公允的句子层落点，`references/polish-strategy.md` §④）。

## ⑥ 用法纪律

- **片段，不是模板**：按具体事实改写后使用；两个段落不共用同一开篇。
- 术语位照 ledger 的 canonical form 填（短语不豁免术语纪律）。
- 数据位填真实统计量（逐字搬运），不填"显著 / 大幅"这类空位。
- 本 bank 不回答"这段要做什么"——那是章职能与三元的事。

## Inbox — 顺手新短语的投放区

**积累模式**（sci-respond phrasebank 先例）：session 尾，把本章 polish 中用着顺手的新短语丢进来——原文一句 + 场景一行（哪章哪类句），不分类、不打磨。隔几个 session vet 一轮：好的提进上面各节，其余删。**别让一个好短语因为分类麻烦而死。**"顺手"的判据就一条：这次用了它，句子变好了——下次遇到同类句还会想用它。

格式（松散，三样齐就行）：

```
- 原文: "……" / 场景: §4.2 局限段 / 建议: ③
```
