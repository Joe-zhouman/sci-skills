## ① 校准原则（先读：什么不是 AI 痕迹）

**去 AI 味 = 语体自然化，面向读者语感；不是检测器特征优化。** 检测器认的是统计特征（用词可预测性、句长变化），读者认的是"痕迹感"，两者只在部分重叠。拿降率判据来杀语体，先死的一定是标准学术连接词。

**标准连接词不是 tell。** 此外 / 然而 / 因此 / 综上所述 / 进一步地——这些是中文学术语体的承重结构。通用 humanizer 的 kill list 常把它们当"AI 高频词"，那是错的：它们承担真实的连接功能。判据看功能，不看词形：

- **"值得注意的是"的边界**：它长得像连接词，实际是填充——后半句若重要，内容自己说话；若不重要，整句删。**连接功能的保留，填充功能的删。**

**三判据（一个短语是 tell，当且仅当满足其一）**：

| # | 判据 | 问的问题 |
|---|---|---|
| a | 零信息 | 删掉它，句子的信息量变了吗？没变 → tell |
| b | 夸大意义 | 它在给内容抬价吗（标志着 / 至关重要 / 奠定基础）？是 → tell |
| c | 机械节奏 | 它是模板化节奏的一部分吗（每段三点 / 等长句 / 固定开场）？是 → tell |

三个都不满足 → 不是 tell，**留**（§⑧ 还有整节的"留"清单）。

**术语一致性是 clarity，不是 weakness。** 通用 humanizer 教你"换个词避免重复"；学位论文正相反——同一术语全文同一写法，读者才不会怀疑你换了概念。never synonym-cycle a technical term：这是 ledger 纪律（`references/polish-strategy.md`），也是 AIGC 降率 L5 杠杆默认不用的同一理由（`references/aigc-playbook.md` §②）。

## ② 内容模式 (content patterns — humanizer #1-6 filtered)

### 夸大意义 → 删，或落具体

触发词：标志着 / 见证了 / 至关重要 / 为…奠定基础 / 为…做出贡献 / 不可或缺 / 关键转折点 / 深远影响。

- 改写前：本文提出的框架标志着该领域研究范式的重要转变，为后续应用奠定了坚实的基础。
- 改写后：本文提出的框架将该指标的检测下限从 0.1 降至 0.02（§3.4）。

### 模糊归因 → 具体引用，或删

触发词：有研究表明 / 专家认为 / 业界普遍认为 / 众所周知 / 多项研究指出（后面却无引用）。**学位论文里无引用的"研究表明"是硬伤**——盲审直接扣，不是语感问题。

- 改写前：研究表明，该类复合材料在高温环境下具有良好的稳定性。
- 改写后：Zhang 等[12]测得该材料在 400 ℃ 下 100 h 内相结构不变。
- 无引用可挂 → 整句删（不编引用——引用纪律见 SKILL.md）。

### 挑战与展望模板 → 具体化，或删

触发词：尽管存在这些挑战 / 仍面临诸多挑战 / 将继续蓬勃发展 / 展现出广阔前景。

- 改写前：尽管本文方法仍存在一定局限，但随着数据不断积累，其应用前景将更加广阔。
- 改写后：本文方法依赖大规模标注数据（§5.3 的 boundary）；若弱监督方案成熟，可扩展到标注成本高的场景。

（展望必须挂在具体 Boundary / limitation 上——`thesis-summary` 的展望 hook 纪律，polish 侧复检同一标准。）

### 宣传语言 → 数量与证据替代

触发词：强大的 / 丰富的 / 深入的 / 高效的 / 优异的。**问题不在单个词，在密度**：堆叠且零信息才是 tell；有证据支撑的单个评价词是正常学术表达。

- 改写前：本文构建了强大的特征提取框架，能够深入挖掘数据中丰富的信息。
- 改写后：框架包含三个尺度的特征分支（图 2），在两个数据集上均优于单尺度基线。

### -ing 式肤浅分析的中文学术对应 → 删，或独立成句并给证据

句尾 dangling 分句：……，从而体现了 / 进而反映了 / 充分展示了 / 这进一步证明了 / 有力支撑了。分句在抬价，不在给信息。

- 改写前：该方法在三个数据集上均取得较高精度，充分展示了其优越性。
- 改写后：该方法在三个数据集上的精度均高于基线 2 个百分点以上（表 3）。
- 判断本身承重时 → 独立成句 + 证据："该增益说明多尺度特征是主要贡献来源（消融实验，表 4）。"

## ③ 语言模式 (lexical patterns — humanizer #7-12)

### AI 高频词表 → 具体化

深入探讨 / 全面提升 / 显著提升 / 极大地促进 / 赋能 / 闭环 / 抓手 / 底层逻辑 / 新范式 / 保驾护航 / 深度融合 / 有力支撑——具体化 = 动词落具体动作，名词落具体对象。

- 改写前：本文深入探讨了温度对反应过程的底层逻辑，为新范式的研究保驾护航。
- 改写后：本文测得温度每升高 50 ℃ 反应速率约提高一倍（§2.3），并据此修正了动力学模型。

### 否定式排比 → 按判断密度规则处理

不仅……更是…… / 不是……而是…… / 既……又……更……。结构本身可承重（术语辨析常用），错在密度——判断规则见 §④ 句式卫生。

### 三段式强制 → 两点或四点，砍充数

每段恰好三点、每组恰好三个形容词——凑数感是 tell。

- 改写前：本文的主要贡献有三：提出了新模型，设计了新损失函数，实现了新的训练流程。
- 改写后（第三点是流程细节、非贡献）：本文的主要贡献有二：提出了新模型，设计了新损失函数。（训练流程的变化随方法章叙述，不进贡献列表。）

### 虚假范围 → 直列实际覆盖

"从 X 到 Y"但 X 与 Y 不在同一有意义的尺度上。

- 改写前：本文的研究涵盖了从分子设计到产业落地的全链条。
- 改写后：本文覆盖分子设计与制备工艺两环（§3-§4），未涉及中试及以后环节。

### 系动词回避 → 是 / 有

发挥着……的作用 / 作为……的重要组成部分 / 构成了……的基础——用复杂结构顶替简单系动词。

- 改写前：间隙原子在相变过程中发挥着至关重要的作用。
- 改写后：间隙原子是该相变的驱动因素（§2.3）。

## ④ 句式卫生 (sentence-pattern hygiene — "不是 X。是 Y。" 密度)

源头是散文写作的固定句式滥用研究；同样适用于论文里的否定 / 转折句式。句式本身没错，错在密度。

**一段一个 controlling idea。** 段落已有论点句（topic sentence）时，不许再"翻"——第二个否定转折是抢戏的第二个论点，第三个就是模板。

**同义回声 ≤ 3。** 同一个判断全文反复强调 → 只留三处：首现（建立论点）、一处承重（证据最强处）、结论（收束）。绪论预告 / 总结收束是结构性位置，不算回声；**同一章内**反复强调同一贡献才是要砍的对象。

**抖包袱 + 后跟解释 → 两层都砍。** 翻完还要解释为什么翻，两层说的同一件事。Y 是抽象词（体现了 / 证明了 / 说明了）时优先落具体——给证据，不给命名。

**删前半前的自检（承重排除不许删）**：删"不是 X"之前先问——读者读到这句之前，会不会真的猜成 X？

- 会猜 → 承重排除，**不能删**，只能改写（吸收进陈述）。术语辨析是常态承重："此处的'稳定性'不是化学稳定性，而是结构稳定性"——两种稳定性读者都会想到，排除承重，留。
- 不会猜 → 空动作，删前半。"本研究的重点不是理论分析。是实验验证。"——读者没猜过理论分析 → "本研究的重点是实验验证。"

- 改写前（翻 + 解释两层）：该偏差不是测量误差。是模型偏差。这说明了模型尚未收敛。
- 改写后：该偏差源于模型未收敛（§4.2）；测量误差已在标定中扣除。

## ⑤ 翻译腔层 (translationese — 学术中文重灾区)

从英文小论文改写中文论文时的主要残留（AIGC 降率 L1 杠杆针对的正是它——`references/aigc-playbook.md` §③）。

### 名词化滥用 → 动词化

"对…的 X" / "…性的构建" / "…的路径"类静态名词结构 → 恢复中文动词。

- 改写前：本节完成对模型参数的优化，并实现对损失收敛性的分析。
- 改写后：本节优化模型参数，并分析损失的收敛性。

### "是…的"强调句滥用 → 直陈

这正是…的 / 该现象是…的体现 / …的所在。

- 改写前：这正是本文方法高效的根本原因所在。
- 改写后：本文方法高效的原因是单次扫描即可采集全谱。

### 英文多义词直译 → 中文直陈

way → "路径"、time → "时点"、mind → "心智"式的名词化直译。

- 改写前：这一发现为理解该机制提供了新的路径。
- 改写后：这一发现为理解该机制提供了新证据（§5.2）。

### 被动句堆叠 → 主动为默认

中文学术以主动为默认；被广泛应用于 / 被认为是 / 被证明是 连排是英文残留。

- 改写前：该算法被广泛应用于工业检测领域，被认为是当前最有效的方案之一。
- 改写后：该算法广泛应用于工业检测（文献[5-7]）。
- 例外：无施动者的术语被动（记为 / 被称为 / 受…影响）是学科惯例，不是 tell。

### 长定语链 → 拆短句

"…的…的…的"定语堆叠，中心词被埋。

- 改写前：基于深度学习的具有多尺度特征融合能力的用于表面缺陷检测的神经网络模型。
- 改写后：本文构建一种表面缺陷检测模型，基于深度学习并融合多尺度特征（图 1）。

### a/an 直译 → 删量词

"一个"滥用：提出了一个模型、构建了一个数据集——学位论文里多半是 a/an 直译。

- 改写前：本文提出了一个新的模型，并构建了一个新的数据集。
- 改写后：本文提出了新模型，并构建了相应数据集。

## ⑥ AI 初稿特征 (draft-stage tells — 弱化版)

比叙事散文弱一档：这些特征"不纠不算错，纠了顺很多"。

**体态字缺失。** 裸动词悬在动作起点，没落地。学术文体只补**句末承重处**，不逐词补：摘要 / 结论里"提出 / 实现 / 构建"补完成态（提出了 / 实现了）；方法章流程动词（加压 → 保温 → 冷却）**不补**——流程用无标记动词是惯例，补了反而错。

- 改写前（摘要）：本文提出一种新方法，实现两类参数的同步调控，并验证其有效性。
- 改写后：本文提出了一种新方法，实现了两类参数的同步调控，并验证了其有效性。

**句长均一。** 全段 25-30 字等长句 → 长短交错。分章区别对待（style-guardrails 的 per-section burstiness 目标）：方法章可均一（操作步骤天然等长）；绪论 / 结论**不应**均一——一句短句（≤10 字）能打断一排长句的节拍器感。

**段长均一。** 每段恰好 4-5 句的模板感 → 变奏：两句话的短段跟在十句话的长段后面，本身就是节奏。

## ⑦ 学位论文特有 tell (thesis-specific tells)

章职能层的诊断归 `references/chapter-guide.md`；本节管这些 tell 的句子层修复。

**各章小结 = 本章摘要复读。** 小结写成第三遍方法叙述（"本章首先介绍了…，然后分析了…"）→ 小结该承接：本章回答了什么 → 遗留什么引出下章。

- 改写前：本章首先介绍了 X 的基本原理，然后分析了影响因素，最后通过实验验证了方法有效性。
- 改写后：本章回答了 §1.3 的 gap-2：影响因素经机理分析确认为主导因素（§2.4）。遗留的问题是多因素耦合情形，下一章的 Y 方法正是针对它。

**展望空洞。** "未来可进一步研究 / 推广到更多场景" → 从 Boundary 落具体的 next question（每个展望项挂一个具体 Boundary 或 limitation）。

- 改写前：未来可将本文方法推广应用到更多领域，具有广阔的研究前景。
- 改写后：本文方法依赖大规模标注数据（§5.3）；若弱监督方案成熟，可扩展到标注成本高的场景。

**绪论 textbook 化。** 第一章写成教材综述（背景知识铺陈、无自己的问题）→ positioning：综述为 gap 服务。

- 改写前：深度学习是机器学习的一个重要分支。卷积神经网络由 LeCun 等提出，其主要特点是局部连接和权值共享……（整节教材口吻，收不到问题上）
- 改写后：卷积神经网络的局部连接特性适合缺陷检测的局部纹理任务（§1.2 综述），但对跨尺度的缺陷仍受限于感受野单一——这是本文 gap-1 的来源。

**摘要背景淹没贡献。** 摘要前三分之二是领域背景 → 背景 1-2 句，问题与贡献为主。

- 改写前：随着人工智能技术的快速发展，深度学习在各个领域得到了广泛应用。在工业制造领域，表面缺陷检测是保证产品质量的关键环节。传统的检测方法存在效率低、成本高等问题……（三段后才见本文工作）
- 改写后：表面缺陷检测依赖人工目检，效率与一致性不足。本文提出 X 方法解决该问题：……（背景一句 → 问题 → 贡献 → 定量结果）

## ⑧ 什么时候留 (what stays)

kill list 滥杀的第一个受害者就是标准学术句式。以下是保护清单：

- **标准学术句式**：本文提出 / 实验表明 / 结果表明 / 表 X 给出 / 如图 X 所示 / 如式 (X) 所示——语体的承重惯例，不是 tell。
- **学科惯例表达**：记为 / 称为 / 定义如式 (X) / 不失一般性 / 记作——术语定义的固定句式。
- **术语的必要重复**：同一术语全文反复是 clarity（ledger 纪律，§①），换同义词才是错。
- **作者风格**：去多余，不去风格。作者既有的句式偏好 / 详略习惯不强行抹平——本层目标是消灭 AI 痕迹，不是统一文风。

**改完的验证**：通读一段，若每句都在"翻"（否定 / 转折）或都在"强调"（强化词 / 排比），还没改干净，再过一轮。这些模式在成稿里该像标点一样稀疏，不该像鼓点一样密集。
